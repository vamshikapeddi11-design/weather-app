# Weather Forecast Web App

## Description
A modern and responsive Weather Forecast Web App built using HTML, CSS, and JavaScript that provides real-time weather updates, hourly forecasts, and weekly forecasts for any city using live weather APIs.

## Features
- Real-time weather updates
- Hourly forecast
- Weekly forecast
- Dynamic weather icons
- Live date and time
- Responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript
- Open-Meteo API
